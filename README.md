# aoiro-fy12-to-fy3

会計ソフト『みんなの青色申告』に暦年（1/1〜12/31）の形で記帳した帳簿から、
3月決算（4/1〜翌3/31）の総勘定元帳（PDF）と決算書（xlsx）を作るツール。

ソフト上の年度データ N は、そのまま N年4月1日〜(N+1)年3月31日 の1期分として扱う。
N年1〜3月の日付は (N+1)年に、決算月（`N/13`）は (N+1)/03/31 の決算整理に読み替える。

## 準備

```sh
python -m venv .venv
.venv/bin/pip install -e ".[dev]"
# 元帳PDFの日本語フォント（見つからなければ Windows の BIZ UDゴシック等を探す）
sudo apt install fonts-ipaexfont-gothic
```

## 設定とデータ

団体名・補助科目名・期首残高などの団体固有の値は、リポジトリ外のデータフォルダに置く。

```
<データフォルダ>/
  org.yaml          … config/org.example.yaml を元に作る
  accounts.yaml     … config/accounts.example.yaml を元に作る
  仕訳帳/仕訳日記帳-<年度>.csv   … ソフトの仕訳日記帳（CP932）
  残高試算表/ 決算書/            … verify で照合するソフトの出力（任意）
```

## 使い方

```sh
# 総勘定元帳PDF・決算書（正式様式の xlsx と、検証用のソフト様式の xls）を作る
python -m aoiro_fy12_to_fy3 build --config <データフォルダ>/org.yaml --year 2017 --out out
python -m aoiro_fy12_to_fy3 build --config <データフォルダ>/org.yaml --all --out out

# 帳簿の整合性を検証し、ソフトの合計残高試算表PDF・決算書xlsと照合する
python -m aoiro_fy12_to_fy3 verify --config <データフォルダ>/org.yaml --all
```

`build` は出力の前に次の点を検証し、問題があれば出力しない（`--force` で出力する）。

- 全仕訳・期末試算表の貸借一致
- 貸借対照表の資産合計 ＝ 負債・正味財産合計、正味財産の内訳と合計の一致
- 前期末残高 → 当期首残高のつながり（繰越正味財産には前期の当期正味財産増減額を加える）
- 複合（仮勘定）の期末残高 ＝ 0、任意積立金の補助科目別残高がマイナスでないこと

金額0円の仕訳は読み込むが元帳には出さず、実行ログに一覧で出す。

## 毎年の決算の手順

ソフト上の年度データ N の期（N年4月1日〜(N+1)年3月31日）が終わったら、次の順に行う。

1. **ソフトで記帳を終える**
   翌年1〜3月の取引を「N年1〜3月」の日付で、決算整理仕訳を決算月（`N/13`）で記帳する。
2. **ソフトから出力してデータフォルダに置く**
   - 仕訳日記帳（CSV）→ `仕訳帳/仕訳日記帳-N.csv`（期間は1月〜決算月）
   - 照合用（任意だが推奨）: 決算月度の合計残高試算表（PDF）→ `残高試算表/`、決算書（xls）→ `決算書/`
3. **新しい科目・補助科目があれば設定に追加する**
   `accounts.yaml` にない科目コードがあると、`verify`・`build` がエラーでコードを知らせる。
   ソフトの勘定科目一覧を見て追加する。任意積立金の補助科目を新しく作ったときも追加する。
4. **検証する**
   ```sh
   python -m aoiro_fy12_to_fy3 verify --config <データフォルダ>/org.yaml --all
   ```
   全期が `[OK]` になることを確かめる。期首残高は最初の期から順に計算するので、過去の年度の仕訳日記帳もすべて置いたままにしておく。
   食い違いが出たら、ソフト側のデータ（出力し直し・記帳の誤り）を確認する。
5. **出力する**
   ```sh
   python -m aoiro_fy12_to_fy3 build --config <データフォルダ>/org.yaml --year N --out out
   ```
   `out/総勘定元帳/総勘定元帳(…_第NN期).pdf`（監査用）、`out/決算書/決算書(…_第NN期).xlsx`（総会用の正式様式）、
   `out/決算書/決算書(…_第NN期).xls`（ソフト様式。ソフトの決算書と見比べる検証用）ができる。
   出力先のフォルダ構成とファイル名は `org.yaml` の `outputs` で変えられる。
   金額0円の仕訳は元帳から除かれ、実行ログに一覧が出るので、意図どおりか確認する。
